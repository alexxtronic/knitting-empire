# The characters' mumble voices

`mumble_1.wav` to `mumble_5.wav` are made by `tools/make_voice.py` from five short syllables in
dodrio's "dialogue_mumble" set on Freesound. They are CC0 (public domain): no credit is required, but
it's given here anyway.

| File | Source | Author | Licence |
|---|---|---|---|
| `mumble_1.wav` | [dialogue_mumble_hah](https://freesound.org/people/dodrio/sounds/554019/) | dodrio | CC0 1.0 |
| `mumble_2.wav` | [dialogue_mumble_heh](https://freesound.org/people/dodrio/sounds/554018/) | dodrio | CC0 1.0 |
| `mumble_3.wav` | [dialogue_mumble_huh](https://freesound.org/people/dodrio/sounds/554017/) | dodrio | CC0 1.0 |
| `mumble_4.wav` | [dialogue_mumble_huuh](https://freesound.org/people/dodrio/sounds/554023/) | dodrio | CC0 1.0 |
| `mumble_5.wav` | [dialogue_mumble_haeh](https://freesound.org/people/dodrio/sounds/554020/) | dodrio | CC0 1.0 |

They were made from Freesound's public high-quality previews (128 kbps MP3), because the originals
need a signed-in download. To rebuild them from the original OGGs, download the five into a folder
named `hah.ogg`, `heh.ogg`, `huh.ogg`, `huuh.ogg` and `haeh.ogg` and run the script on that folder.
